# Andriyana Abdullah Aziz — Junior Data Analyst CV

A static personal CV website built with HTML, CSS, and JavaScript.

## Files

- `index.html` — CV content
- `style.css` — responsive styling and print stylesheet
- `script.js` — theme toggle and current year
- `cv.pdf` — PDF CV attached to the site

## GitHub Pages

1. Create a GitHub repository, for example `andriyana-cv`.
2. Upload all files in this folder.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select `main` and `/ (root)`, then Save.
6. GitHub Pages will publish the site.

For a personal site URL such as `https://USERNAME.github.io`, GitHub requires the repository name `USERNAME.github.io`.
